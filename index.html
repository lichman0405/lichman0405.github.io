01 / SCIENTIFIC AGENTS

RAVEL

A research runtime that tracks a scientific plan, the state of each task, and the evidence an independent reviewer needs to assess the result. The public V0 uses simulated compute and laboratory backends.

RAVEL on GitHub ↗

02 / SOFTWARE VERIFICATION

SURE

Evaluates claims made by coding agents against evidence from the software. It reports what it can verify, defines a focused repair when it finds an issue, and checks the result after the fix.

SURE on GitHub ↗

03 / MATERIALS MODELLING

MIRA

A FastAPI benchmark service for comparing machine-learned interatomic potentials on metal-organic frameworks. Model families run in separate containers so their dependencies stay isolated.

MIRA on GitHub ↗

04 / MOLECULAR SIMULATION

raspa-mcp

Wraps RASPA2 in structured tools so agents can prepare simulations, run calculations such as GCMC adsorption, and parse the outputs.

02 / BACKGROUND

From chemistry to AI

I lead AI and materials research at MiQroEra in Shanghai. My work spans agent architecture, FastAPI and MCP integrations, and computational screening of metal-organic frameworks for CO₂ capture and water harvesting.

I helped set up a MOF lab and built tools for batch analysis of characterisation data. Earlier, I worked independently on recommendation systems, predictive analytics, and data pipelines.
